## 当前试用规则

### 标题

- 68–75字符，空格、标点均计数，前后端校验。
- 商品身份准确，以实际所售产品开头。材料、配件、使用对象、宽泛场景不能冒充商品。
- 可用足够时至少2个独立关键词，尽量覆盖3个；不足2个按实际可用数量。
- 高流量词优先，但不挤掉实际商品身份，不用关键词清单代替自然标题。

### 亮点

亮点是一段最多125字符的英文短文，不是五条长卖点；不设100字符下限。

先理解：

1. 实际是什么产品、适合谁。
2. 在什么具体场景使用。
3. 功能帮助完成什么任务、解决什么问题。
4. 有哪些已提供、影响购买判断的适用条件和限制。

四点用于选材，不要求在125字符内机械写全。优先选择一个具体功能及其直接使用帮助，结合有依据的场景或人群。没有提供的人群、条件、限制留空；不编造速度、安全、耐用、兼容性等性能承诺。

- 不设置亮点关键词数量门槛，完整词组命中只用于辅助展示。
- 不用“多个同义词＋功能短句”的固定候选结构。
- 可以自然调整关键词语序、单复数，不强制承接标题剩余词。
- 标题已清楚表达的信息不机械重复；重要变体须在两字段中至少保留一次。
- 前后端按实际长度拦截超过125字符的亮点，不自动截断。

## 保留的线上优化

- 至少一张可读关键词及流量占比或月搜索量截图即可；支持JPG/PNG/WebP，每张最多8MB。
- 原标题必填，参考标题选填且视为人工确认；当前身份和变体以原标题为准。
- 两类指标各自识别，不混算；月搜索量不能冒充流量占比。
- 异步任务、短请求轮询、刷新后恢复等待；不会因浏览器重连重复提交模型任务。
- 首次文案/JSON校验失败，带实际字数和错误最多重新生成1次；不重复识图及资料整理。
- 所有方舟调用关闭深度思考；写作额度8192 tokens。
- 识图及资料整理每阶段最长180秒，写作每次最长300秒。
- 英文结构检查及模型同次语义自检保留。模型自检仅是辅助，不代表质量保证。

## 启动与密钥

Python 3.9+，无第三方Python运行依赖。在项目目录执行 `python3 server.py`，或使用原有启动脚本。

本机服务从 `ARK_API_KEY` 环境变量或macOS钥匙串 `prompt-tool.api-keys` / `ARK_API_KEY` 读取密钥，不把密钥放入网页或Git。默认识图/整理 `doubao-seed-2.1-lite`，写作 `doubao-seed-2.1-pro`。

后台运行数据及日志位于用户目录 `Library/Application Support/title-tool`；不会放进公开源码目录。任务按用户隔离、保留24小时。输入草稿和最近10条历史保存在当前浏览器，原有历史保留并标注旧规则；不通过Git同步。

只读状态：`/api/health`，返回规则版本、模型、是否配置密钥，不返回密钥本身。
